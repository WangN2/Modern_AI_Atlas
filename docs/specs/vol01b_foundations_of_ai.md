3. **1970s** 知识表示 / 专家系统兴起
4. **1980s** 机器学习起步 / 统计方法引入
5. **1990s** 神经网络复兴 / 深度学习萌芽
6. **2000s** 大数据与计算 / 能力提升
7. **2010s** 深度学习突破 / 大规模应用
8. **2020s** 大模型与通用智能 / 新时代开启

### 3.2 Three-column row: 核心概念 / 学科分支 / 关键人物

**AI 核心概念 (Core Concepts)** — donut wheel around center 人工智能 AI; 5 colored segments:

- 学习 Learning — 从数据中学习 (green)
- 推理 Reasoning — 逻辑思考与决策 (orange)
- 知识表示 Knowledge — 表示与组织知识 (purple)

Below the wheel: **智能体 (Agent)** strip: 感知环境 → 理解 → 推理 → 行动 → 反馈

**AI 学科分支地图 (Discipline Map)** — radial map around center 人工智能 AI; 8 branches with bullet items:
- 计算机科学 Computer Science: 算法与数据结构 / 计算理论 / 编程语言
- 数学 Mathematics: 线性代数 / 概率与统计 / 优化理论
- 机器学习 Machine Learning: 监督学习 / 无监督学习 / 强化学习
- 统计学 Statistics: 数据建模 / 假设检验 / 回归分析
- 语言学 Linguistics: 自然语言理解 / 语义与语法 / 语言生成
- 认知科学 Cognitive Science: 人类认知建模 / 心理学 / 神经科学

- 哲学 Philosophy: 逻辑学 / 知识论 / 心智哲学

**关键人物 (Key Figures)** — 5 portrait rows (photo + name + 2-3 lines zh):
- **Alan Turing** — 计算机科学之父 / 提出"图灵测试" / 奠定了 AI 的理论基础
- **John McCarthy** — AI 之父 / 提出"人工智能"术语 / LISP 语言发明者

### 3.3 Two-column row: 范式演进 / 能力层次

**AI 范式演进 (Paradigm Evolution)** — 5 vertical cards left→right with icons:
1. 符号主义 (1950s-1980s) — 基于规则与逻辑: 专家系统 / 知识推理
2. 连接主义 (1980s-2000s) — 神经网络模型: 模式识别 / 学习表示
3. 统计学习 (2000s-2010s) — 概率建模: 数据驱动 / 机器学习
4. 深度学习 (2010s-至今) — 多层神经网络: 端到端学习 / 大规模数据
5. 大模型时代 (2020s-未来) — 预训练 + 微调: 通用能力 / 多模态理解

**AI 能力层次 (Capability Hierarchy)** — 5-level pyramid, bottom→top, with right-side axis 基础能力 (bottom) → 高阶能力 (top):
1. 感知 (Perceive) — 感知与识别现实世界
2. 理解 (Understand) — 语义理解，知识归纳
3. 推理 (Reason) — 逻辑思考，因果推理
4. 决策 (Decide) — 做出最优或合理的选择
5. 创造 (Create) — 生成新内容，提出新想法

**知识表示方法 (Knowledge Representation)** — 6 small cards (icon + zh/en + 3 bullets):

4. 框架表示 (Frame): 槽位结构 / 默认值 / 继承机制
5. 本体表示 (Ontology): 概念层次 / 属性约束 / 语义一致性
6. 向量表示 (Vector): 分布式表示 / 嵌入空间 / 语义相似性

Below: arrow strip **从符号化表示 → 到分布式表示 → 再到神经表示**
