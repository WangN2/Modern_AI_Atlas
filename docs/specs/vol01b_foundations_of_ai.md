### 3.4 AI 基础问题

### 3.6 Two-column row: 范式演进 / 能力层次

**AI 范式演进 (Paradigm Evolution)** — 5 vertical cards left→right with icons:
1. 符号主义 (1950s-1980s) — 形式逻辑与搜索 / 产生式与专家系统 / 知识由人显式编码 / 可解释但脆弱
2. 连接主义 (1980s-1990s) — 感知机与反向传播 / 分布式表示 / 从样本学习权重 / 难解释但更鲁棒
3. 统计学习 (2000s-2010s) — 核方法与贝叶斯 / 泛化与正则化 / 特征工程主导 / 小数据下可控建模
4. 深度学习 (2010s-至今) — CNN/RNN/Transformer / 端到端表示学习 / GPU 与大数据驱动 / 任务专用模型突破
5. 大模型时代 (2020s-未来) — 自监督预训练 / 提示、微调与对齐 / 多模态与工具使用 / 同一模型迁移多任务

**AI 能力层次 (Capability Hierarchy)** — 5-level pyramid, bottom→top, with right-side axis 基础能力 (bottom) → 高阶能力 (top):
1. 感知 (Perceive) — 感知与识别现实世界
2. 理解 (Understand) — 语义理解，知识归纳
3. 推理 (Reason) — 逻辑思考，因果推理
4. 决策 (Decide) — 做出最优或合理的选择
5. 创造 (Create) — 生成新内容，提出新想法

### 3.9 现代 AI 系统五层栈

**Modern AI System Stack** — five cards that connect foundations to deployable systems:

1. 数据与知识 (Data): 语料/图像/传感器 / 标注、合成与清洗 / 知识库与检索语料
