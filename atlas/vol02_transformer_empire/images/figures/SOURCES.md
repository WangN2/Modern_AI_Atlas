# Vol.02 Figure Sources

These figures are embedded in the Vol.02 SVG as attributed supporting
examples. Poster text remains editable SVG text; the figures are not used as
full-poster screenshots.

| File | Source | Figure used |
|---|---|---|
| `transformer_architecture.png` | Vaswani et al., [Attention Is All You Need](https://arxiv.org/pdf/1706.03762) (2017) | Figure 1, the original encoder-decoder Transformer architecture. The paper grants permission to reproduce figures in scholarly works with attribution. |
| `vit_overview.png` | Dosovitskiy et al., [An Image is Worth 16x16 Words](https://arxiv.org/abs/2010.11929) (2020) | Figure 1, patch projection and the Vision Transformer encoder. |
| `clip_overview.png` | Radford et al., [Learning Transferable Visual Models From Natural Language Supervision](https://arxiv.org/abs/2103.00020) (2021) | Figure 1, contrastive pretraining and zero-shot transfer. |
| `dit_block.png` | Peebles and Xie, [Scalable Diffusion Models with Transformers](https://www.wpeebles.com/DiT) (2022/2023) | Official DiT block-design comparison from the project page. |

The files are kept beside the volume data so builds remain deterministic and
do not require network access.
